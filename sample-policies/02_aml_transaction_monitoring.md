# นโยบายการเฝ้าระวังธุรกรรมต้องสงสัยและรายงาน ปปง. (AML/CTRF) (COMP-POL-2026-02)

- **รหัสเอกสาร:** COMP-POL-2026-02
- **หน่วยงานที่รับผิดชอบ:** Compliance (ฝ่ายกำกับการปฏิบัติตามกฎเกณฑ์)
- **เวอร์ชัน:** 2026.1
- **สถานะ:** บังคับใช้

## หมวดที่ 1: เกณฑ์การรายงานธุรกรรมที่ใช้เงินสด (Cash Transaction Report: CTR)
ตามพระราชบัญญัติป้องกันและปราบปรามการฟอกเงิน ธนาคารมีหน้าที่ต้องรายงานธุรกรรมที่ใช้เงินสด (CTR) ต่อสำนักงานป้องกันและปราบปรามการฟอกเงิน (สำนักงาน ปปง. / AMLO) เมื่อลูกค้าทำธุรกรรมฝาก ถอน ซื้อขายตราสาร หรือโอนเงินด้วยเงินสดผ่านเคาน์เตอร์สาขาหรือเครื่องรับฝากเงินสดอัตโนมัติ ที่มีมูลค่าตั้งแต่ **2,000,000 บาทขึ้นไป** ต่อครั้ง หรือมีการทำธุรกรรมเงินสดหลายรายการรวมกันใน 1 วันทำการมีมูลค่าตั้งแต่ **2,000,000 บาทขึ้นไป** โดยพนักงานผู้ทำรายการต้องให้ลูกค้ากรอกแบบฟอร์มบันทึกข้อเท็จจริงเกี่ยวกับแหล่งที่มาของเงินและวัตถุประสงค์ของธุรกรรมทุกครั้ง

## หมวดที่ 2: เกณฑ์การรายงานธุรกรรมโอนเงินทางอิเล็กทรอนิกส์และธุรกรรมเกี่ยวกับทรัพย์สิน
1. **การโอนเงินทางอิเล็กทรอนิกส์ (Electronic Wire Transfer):** กรณีการโอนเงินหรือชำระเงินทางอิเล็กทรอนิกส์ข้ามพรมแดน หรือการโอนเงินภายในประเทศผ่านระบบอิเล็กทรอนิกส์ที่มีมูลค่าตั้งแต่ **100,000 บาทขึ้นไป** ระบบต้องตรวจสอบและบันทึกข้อมูลผู้ส่งโอน (Originator) และผู้รับโอน (Beneficiary) ให้ครบถ้วนตามหลักเกณฑ์ Wire Transfer Rule และรายงานธุรกรรมที่มีมูลค่าตั้งแต่ **500,000 บาทขึ้นไป** ตามหลักเกณฑ์ที่สำนักงาน ปปง. กำหนด
2. **ธุรกรรมที่เกี่ยวกับทรัพย์สินหรืออสังหาริมทรัพย์:** การทำธุรกรรมสินเชื่อหรือการชำระราคาที่เกี่ยวข้องกับอสังหาริมทรัพย์หรือทรัพย์สินที่มีมูลค่าตั้งแต่ **5,000,000 บาทขึ้นไป** ต้องจัดทำรายงานส่งต่อสำนักงาน ปปง. ตามกำหนดเวลา

## หมวดที่ 3: การรายงานธุรกรรมที่มีเหตุอันควรสงสัย (STR) และระยะเวลาเก็บรักษาข้อมูล
หากพนักงานสาขาหรือระบบตรวจจับธุรกรรมอัตโนมัติ (AML Transaction Monitoring System) พบพฤติกรรมผิดปกติ เช่น การจงใจแตกยอดเงินสดหลายรายการเพื่อหลีกเลี่ยงเกณฑ์ 2,000,000 บาท (Structuring / Smurfing) การใช้บัญชีพักเงินที่มีเงินโอนเข้า-ออกถี่ผิดปกติในลักษณะบัญชีม้า (Mule Account) หรือธุรกรรมที่ไม่มีเหตุผลทางเศรษฐกิจรองรับ ให้ดำเนินการดังนี้
- พนักงานผู้ตรวจพบต้องแจ้งเตือนผ่านระบบ AML Alert มายัง **ฝ่าย AML Compliance ภายใน 24 ชั่วโมง** นับตั้งแต่พบความผิดปกติ
- ฝ่าย AML Compliance ต้องตรวจสอบข้อเท็จจริงและยื่นรายงานธุรกรรมที่มีเหตุอันควรสงสัย (Suspicious Transaction Report: STR) ต่อสำนักงาน ปปง. **ภายใน 7 วันทำการ** นับแต่วันที่มีเหตุอันควรสงสัย
- ห้ามมิให้พนักงานเปิดเผยข้อมูลหรือแจ้งให้ลูกค้าทราบว่ากำลังถูกตรวจสอบหรือถูกรายงาน STR โดยเด็ดขาด (Strict Prohibition of Tipping-Off)
- ธนาคารต้องเก็บรักษาเอกสารหลักฐานการแสดงตนของลูกค้า (KYC/CDD) และประวัติการทำธุรกรรมทางการเงินทั้งหมดไว้เป็นระยะเวลาไม่น้อยกว่า **10 ปี** นับตั้งแต่วันที่มีการปิดบัญชีหรือยุติความสัมพันธ์ทางธุรกิจ
