# มาตรฐานการตั้งรหัสผ่าน การยืนยันตัวตนหลายปัจจัย (MFA) และสิทธิ์ขั้นสูง (IT-POL-2026-02)

- **รหัสเอกสาร:** IT-POL-2026-02
- **หน่วยงานที่รับผิดชอบ:** IT (ฝ่ายความมั่นคงปลอดภัยทางสารสนเทศ)
- **เวอร์ชัน:** 2026.2
- **สถานะ:** บังคับใช้

## หมวดที่ 1: มาตรฐานความซับซ้อนและอายุของรหัสผ่าน (Password Policy)
1. **รหัสผ่านผู้ใช้งานทั่วไป (Standard User Password):** พนักงานทุกคนต้องตั้งรหัสผ่านเข้าใช้งานระบบองค์กรความยาวอย่างน้อย **12 ตัวอักษร** โดยต้องประกอบด้วยอักขระอย่างน้อย 4 ประเภท ได้แก่ ตัวอักษรภาษาอังกฤษพิมพ์ใหญ่ (A-Z) ตัวอักษรพิมพ์เล็ก (a-z) ตัวเลข (0-9) และอักขระพิเศษ (เช่น `@`, `#`, `$`, `%`, `!`)
2. **รหัสผ่านผู้ดูแลระบบขั้นสูง (Privileged Admin Password):** สำหรับบัญชีผู้ดูแลระบบและฐานข้อมูล ต้องมีความยาวรหัสผ่านอย่างน้อย **16 ตัวอักษร**
3. **รอบการเปลี่ยนรหัสผ่านและการห้ามใช้ซ้ำ:** ระบบจะบังคับให้พนักงานเปลี่ยนรหัสผ่านทุกๆ **90 วัน** (สำหรับบัญชีผู้ดูแลระบบขั้นสูงต้องเปลี่ยนทุกๆ **60 วัน**) และระบบจะไม่อนุญาตให้ตั้งรหัสผ่านซ้ำกับรหัสผ่านเดิมย้อนหลัง **12 ครั้ง** (Password History = 12)

## หมวดที่ 2: การยืนยันตัวตนหลายปัจจัย (MFA) และการล็อกบัญชีอัตโนมัติ (Account Lockout)
- **การเปิดใช้งาน MFA:** พนักงานทุกคนต้องเปิดใช้งานการยืนยันตัวตนหลายปัจจัย (**Multi-Factor Authentication: MFA**) ผ่านแอปพลิเคชัน Authenticator หรือฮาร์ดแวร์โทเคน (FIDO2 / YubiKey) ทุกครั้งที่เข้าสู่ระบบเครือข่ายธนาคาร ระบบอีเมล ระบบ Core Banking และระบบ VPN (ไม่อนุญาตให้ใช้ SMS OTP สำหรับการเข้าถึงระบบงานสำคัญของผู้ดูแลระบบ)
- **การระงับบัญชีเมื่อป้อนรหัสผิด (Account Lockout):** หากมีการป้อนรหัสผ่านผิดติดต่อกันครบ **5 ครั้ง** ระบบจะทำการล็อกบัญชีผู้ใช้งานโดยอัตโนมัติเป็นเวลา **30 นาที** หรือจนกว่าจะได้รับการยืนยันตัวตนเพื่อปลดล็อกผ่านแผนก IT Helpdesk
- **การตัดการเชื่อมต่ออัตโนมัติ (Session Timeout):** หน้าจอระบบปฏิบัติการและแอปพลิเคชันภายในจะทำการล็อกหน้าจอหรือตัดการเชื่อมต่ออัตโนมัติ (Idle Session Timeout) เมื่อไม่มีการเคลื่อนไหวหรือใช้งานเกินกว่า **15 นาที**

## หมวดที่ 3: การควบคุมสิทธิ์ขั้นสูง (PAM) และการทบทวนสิทธิ์ผู้ใช้งาน
- **การเบิกใช้สิทธิ์ผู้ดูแลระบบ (Just-In-Time PAM):** การเข้าถึงเซิร์ฟเวอร์ในสภาพแวดล้อมใช้งานจริง (Production Environment) ต้องเบิกใช้สิทธิ์ชั่วคราวผ่านระบบ Privileged Access Management (PAM) โดยอนุมัติให้ใช้งานได้ครั้งละไม่เกิน **4 ชั่วโมง** พร้อมทั้งบันทึกประวัติคำสั่งและวิดีโอหน้าจอตลอดการใช้งาน
- **การเพิกถอนสิทธิ์เมื่อพ้นสภาพพนักงาน:** กรณีพนักงานลาออกหรือสิ้นสุดสัญญาจ้าง ฝ่ายทรัพยากรบุคคลต้องแจ้งฝ่าย IT เพื่อระงับและเพิกถอนสิทธิ์การเข้าถึงระบบทั้งหมดภายใน **4 ชั่วโมง** (และต้องระงับทันทีในวินาทีที่มีการแจ้งให้ออกจากงานกรณีกระทำผิดวินัยร้ายแรง)
- **การทบทวนสิทธิ์ประจำไตรมาส (User Access Review):** ผู้จัดการฝ่ายทุกหน่วยงานต้องทำการตรวจสอบและรับรองความเหมาะสมของสิทธิ์ผู้ใช้งานในสังกัด (User Access Matrix Review) ร่วมกับฝ่าย IT Security อย่างน้อยทุกๆ **90 วัน (รายไตรมาส)**
